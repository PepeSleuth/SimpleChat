# SimpleChat

FOSS AI Chat App wrapping OpenRouter.

## Features

- Branching conversations
- File uploads
- Web search is always available to the model; search activity appears in the reasoning dropdown.
- Opt-in YouTube video input for links in your latest message (requires a compatible model/provider). YouTube and LaTeX toggles start off on each page load.
- Ask the assistant to find past conversations, with links and supporting excerpts (requires a model that supports tools). Searches saved titles and message text across projects; relevant excerpts are sent to your selected model only when it searches. Attachment contents are not searched.
- Projects
- JSON Import/Export
